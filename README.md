# Voicepeak-中文用户词典

使用「活字印刷」拼出来的中文，收录国标一级汉字（常用字）。

> VoicePeak 只有日语音源。这个词典把中文字映射成日语假名读音，
> 让日语音源「照着假名」读出接近普通话的声音。

---

## 📚 项目简介

本仓库提供一个收录 **国标一级汉字（3755 字）** 的 VoicePeak 用户词典，
以及配套的**词典开关工具**，用于在「中文朗读」和「日文朗读」之间随时切换。

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `词典库_中文.vdc2` | 词典库主文件，包含国标一级汉字完整列表 |
| `VoicepeakDictToggle.ps1` | 词典开关脚本（核心逻辑，纯 PowerShell，可审阅） |
| `切换-日文模式.bat` | 双击：停用中文字典，恢复日文正常读音 |
| `切换-中文模式.bat` | 双击：重新启用中文字典 |

## ⚠️ 导入后怎么切回日文（重要）

### 问题

导入后词典是**全局生效**的：只要它在，VoicePeak 念任何文本都会优先套用中文读音，包括日文。

比如日文里常见的 `本`、`私`、`先輩`、`神`，会被读成 ベン、スー、シェン、シェン，
而不是 ほん、わたし、せんぱい、かみ。结果是：**你想用日文时，反而没法正常用了。**

GUI 里「词典 → 三点 → 清空」确实能解决，但只能**一条一条删**，3755 条不现实。

### 原理

VoicePeak 的词典真正存在这里，不是 GUI 里看到的那个文件：

```
C:\ProgramData\Dreamtonics\Voicepeak\user-dictionary\<时间戳>-dic.json
```

程序每次启动时，会把这份 JSON 编译成两个文件：

```
%LOCALAPPDATA%\Dreamtonics\Voicepeak\settings\user.csv   ← 导出视图
%LOCALAPPDATA%\Dreamtonics\Voicepeak\settings\user.dic   ← 实际生效的编译产物
```

所以**只删 `user.csv` / `user.dic` 是没用的**——下次启动会从 JSON 重新生成。
要停用词典，必须动那个 JSON。

### ✅ 方法一：一键脚本（推荐）

双击仓库里的两个批处理文件：

| 文件 | 作用 |
|------|------|
| `切换-日文模式.bat` | 停用中文字典，日文汉字按日语读音 |
| `切换-中文模式.bat` | 重新启用中文字典 |

脚本做的事（可自行审阅 `VoicepeakDictToggle.ps1`）：

1. 把 `user-dictionary` 里的 `*-dic.json` 移到 `dict-disabled\` 备份
2. 删除 `settings\user.csv` 和 `user.dic`
3. 切回中文时，清理空词典并从母本恢复

> ⚠️ **切换前请先完全关闭 VoicePeak**，否则 `user.dic` 被占用会删不掉。
> ⚠️ 需要**管理员权限**（要写入 `ProgramData`），脚本会自动请求。
> ✅ 脚本只**移动**文件，不会删除你的词典。

脚本还做了两层保险：

1. **词典母本**：第一次切换时会把词典复制一份到
   `%LOCALAPPDATA%\Dreamtonics\Voicepeak\dict-master\`，此后不会被覆盖。
2. **自动清理空词典**：VoicePeak 在「无词典」状态下退出时，有时会往
   `user-dictionary` 写回一个内容为 `[]` 的空文件。切回中文时脚本会先删掉这类空文件，再从母本恢复。

### 🔧 方法二：手动操作

1. **关闭 VoicePeak**（任务管理器里确认没有 `voicepeak.exe`）
2. 打开 `C:\ProgramData\Dreamtonics\Voicepeak\user-dictionary\`
3. 把里面所有 `*-dic.json` **剪切**到别的文件夹备份
4. 打开 `%LOCALAPPDATA%\Dreamtonics\Voicepeak\settings\`，删除 `user.csv` 和 `user.dic`
5. 重新启动 VoicePeak —— 现在就是日文模式
6. 想恢复中文：把备份的 JSON 放回去，再删一次第 4 步的两个文件

### 🎧 怎么确认切换成功

用下面这句测试：

```
神様の豆知識
```

- **日文模式**：读作「かみさま」，正常日语
- **中文模式**：`神` 会被读成「シェン」，一听就不对

### ❓ 常见问题

**Q：我删了 `user.csv`，为什么它又回来了？**
A：因为它是 `user.dic` 的导出视图，而 `user.dic` 又是从 `ProgramData` 里的 JSON 编译出来的。
要断根，必须移走 JSON。

**Q：切回中文后，打开软件发现词典是空的？**
A：说明 `user-dictionary` 里只剩一个内容为 `[]` 的空文件（「无词典」状态下运行软件后可能产生）。
用脚本修复：双击 `切换-中文模式.bat`，它会自动处理。
手动修复：删掉那个几字节的 JSON，把备份的词典放回去，再删一次 `settings\user.csv` 和 `user.dic`。

**Q：切换后需要重装词典吗？**
A：不需要。切回中文模式时会自动重建，词条一条不少。

**Q：能不能只停用一部分词条？**
A：可以。`user-dictionary` 里的 JSON 就是词条列表，删掉某几项再启动即可，
也可以在同目录放多份不同用途的 JSON。

**Q：为什么必须管理员权限？**
A：`C:\ProgramData\` 是系统级目录，普通权限只能读不能改。

**Q：会影响软件授权吗？**
A：不会。只动 `user-dictionary` 目录，`Keys` 授权文件不碰。

## 📖 数据来源

本词典库依据 **GB2312** 国家标准收录，涵盖国标一级汉字（常用汉字）全部字符。

## 😥 说明

- 国标二级汉字未收录
- 生僻字未收录
- 多音字只取其中一个读音
- 因为是「日语拼的中文读音」，很难保证读音准确，有的音实在读不准
- 直出效果不算好，仍需要使用者自行调教（音高/语调）
